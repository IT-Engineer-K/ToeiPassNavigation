# ToeiPassNavigation

都営交通（都営地下鉄・日暮里・舎人ライナー・都電荒川線・都営バス）の無料乗車証（障害者手帳等）に対応し、**都営交通（0円）と他社線（通常運賃または障害者割引50%OFF）を組み合わせたトータル最安・最適ルート**を検索できる乗換案内アプリです。

## 主な特徴

- **4パターンの経路を同時比較**
  - **最安ルート（都営フル活用）**：都営区間（0円）を最大限活用し、他社線運賃を最小化
  - **おトク＆時短バランス**：わずかな他社線運賃で大幅に時間短縮できるルートを提案
  - **最速ルート**：所要時間を最優先しつつ、通った都営区間を0円として実支払額を算出
  - **都営交通のみ（完全0円）**：他社線を一切使わない完全無料ルート
- **柔軟な条件切り替え**
  - 都営無料パスの適用 ON/OFF（通常運賃との差額・おトク額を自動表示）
  - 他社線の障害者割引（半額）適用 ON/OFF
  - 都営バス路線の検索対象 ON/OFF
  - IC運賃 / きっぷ運賃の切り替え
- **維持費0円・サーバーレス設計**
  - ルート探索（ダイクストラ法）と距離制運賃通算ロジックをクライアント内で完結
  - GitHub Pages 等の無料ホスティングや PWA / Android アプリ化に対応

## 使い方

1. ブラウザで `index.html` を開くか、ローカルサーバーを起動します：
   ```bash
   npm start
   ```
2. 出発駅と到着駅を選択すると、即座に最安ルート・バランスルート・最速ルートが比較表示されます。

## データの手動更新・検証

ダイヤ改正や運賃改定時は、`data.js` を編集した上で以下のスクリプトを実行すると整合性チェックと `transit-data.json` の出力が行われます：

```bash
node scripts/update-data.js
```
