プライバシーポリシー

Androidアプリ「都営パスナビ（ToeiPassNavi / パッケージ名: com.konju.toeipassnavi）」およびWeb版「ToeiPassNavigation」（以下「本アプリ」）における利用者情報の取り扱いについて定めます。

本アプリの基本方針 本アプリは、端末内で完結する完全オフラインの乗換案内アプリです。個人情報・位置情報・検索履歴・端末識別子などの利用者情報を一切収集・保存・共有・外部送信しません。

01収集する情報について

本アプリは、氏名・メールアドレス・位置情報・検索履歴・利用状況・広告ID・クラッシュログなどの個人情報および機密データを一切収集しません。

  • アカウントの作成やログイン機能はありません。
  • 出発駅・到着駅・時刻・検索条件などの入力内容は、端末内での経路探索と運賃計算にのみ使用され、外部へ送信されることはありません。

02通信および端末権限について

本アプリのAndroid版は、インターネット通信を行いません。また、インターネット権限・位置情報権限・ストレージ権限・カメラ・連絡先などの端末権限を一切要求しません。

路線・運賃データを手動更新するために、利用者が任意でJSONファイルを読み込む機能を利用した場合、Android標準のファイル選択画面（Storage Access Framework）から選ばれたファイルのみを端末内のメモリ上で一時的に読み込みます。ファイルの内容が外部に送信・共有されることはありません。

03広告・解析ツール・外部SDKについて

本アプリは、広告配信SDK（Google AdMob等）、アクセス解析ツール（Firebase Analytics / Google Analytics等）、クラッシュレポート送信ツール、外部AI APIなどのサードパーティ製SDK・外部サービスを一切組み込んでいません。

  • Google Play ストアについて（Android版）：Android端末やGoogleアカウントの設定に応じて、Google LLC がアプリのダウンロード数やOSレベルの診断情報を処理する場合があります。詳細は Google プライバシーポリシー をご確認ください。
  • ホスティングについて（Web版）：Web版（本ページを含む）は Vercel または GitHub Pages 上で公開されており、アクセス時にホスティング事業者によりIPアドレス等の標準的なアクセスログが処理される場合があります。詳細は Vercel Privacy Policy および GitHub プライバシーステートメント をご確認ください。

04第三者提供について

本アプリは利用者情報を収集していないため、第三者への提供・共有・販売を行うことはありません。

05データの管理・保管・削除について

本アプリは外部サーバー上に利用者データを一切保存せず、端末内にも個人情報を永続保存しません。

  • 入力した検索条件や任意で読み込んだJSONデータは端末内のメモリ上でのみ保持され、アプリ終了時・初期データへのリセット時・アンインストール時に自動的に消去されます。
  • アカウント登録機能が存在しないため、アカウント削除の手続きは不要です。

06お子様のプライバシー

本アプリは、13歳未満のお子様を含むすべての年齢層の利用者から個人情報を意図的に収集することはありません。

07免責事項

本アプリが提供する経路・所要時間・運賃情報は参考情報であり、ダイヤ改正・運賃改定・運行状況等により実際の運行内容や運賃と異なる場合があります。本アプリの利用によって生じた損害について、運営者は責任を負いかねます。

08ポリシーの変更

法令の改正や機能の追加・変更に応じて、本ポリシーを改定することがあります。重要な変更がある場合は、本ページまたは本アプリ内でお知らせします。

Privacy Policy (English)

ENSummary & Compliance

ToeiPassNavi / 都営パスナビ (Android package: com.konju.toeipassnavi) and ToeiPassNavigation (Web) do not access, collect, store, transmit, or share any personal or sensitive user data, including names, email addresses, location data, search history, device identifiers, or usage analytics.

  • Offline & No Permissions: The Android app operates completely offline without internet, location, storage, camera, or contacts permissions. Any JSON transit file voluntarily imported via the system file picker (Storage Access Framework) is processed only in temporary device memory and is never sent externally.
  • No Third-Party SDKs: The app does not include advertising SDKs, analytics SDKs, crash reporting tools, or external AI APIs. Platform-level metrics on Google Play or web access logs on Vercel / GitHub Pages are governed by Google's Privacy Policy, the Vercel Privacy Policy, and the GitHub General Privacy Statement, respectively.
  • Data Retention & Deletion: No user data is stored on servers or persisted locally. All in-memory state is cleared when the app closes, resets, or is uninstalled. No account creation is offered, so no account deletion workflow is required.
  • Children's Privacy: The app does not knowingly collect personal information from children under 13 or any other age group.
